Version 1.0

# Purpose

This document establishes the first formally stated lemmas of the
Hebûn operator.

Each lemma follows from the operator definition and its stated
properties. Detailed proofs will be provided in the Proofs module.

---

# Lemma H1

## Deterministic Evaluation

For every state

Ψ

there exists exactly one evaluation

ℍ(Ψ).

---

Consequence

Hebûn is a deterministic operator.

---

# Lemma H2

## Stability Preservation

If

Ψ

is stable,

then

ℍ(Ψ)

remains stable.

---

# Lemma H3

## Consistency Preservation

Hebûn never transforms a consistent state into an inconsistent state.

---

# Lemma H4

## Idempotence

For every validated state

Ψ

ℍ(ℍ(Ψ))

=

ℍ(Ψ)

---

# Lemma H5

## Composition Compatibility

Hebûn is composable with every operator satisfying the Operator
Specification.

---

# Lemma H6

## Information Integrity

Hebûn never increases ontological inconsistency.

---

# Lemma H7

## Category Preservation

Hebûn preserves categorical structure.

Therefore

ℍ

is an endomorphism in
