# Zanabûn Axioms

## Purpose

Zanabûn is the epistemological layer of the Zanistarast Formal Foundations.

If Hebûn answers "What exists?",
Zanabûn answers "How can existence be known correctly?"

Knowledge does not create existence.
Knowledge discovers existence.

---

# Axiom Z1

Every valid knowledge must correspond to an existing reality.

Knowledge(x) ⇒ Hebun(x)

False knowledge has no ontological stability.

# Axiom Z2

Knowledge requires evidence.

Evidence(x) > 0

Claim without evidence
cannot become knowledge.

# Axiom Z3

Knowledge must be reproducible.

If independent observers
cannot reproduce a result,

the result remains unverified.

Knowledge minimizes uncertainty.

As verified knowledge increases,

uncertainty decreases.

Knowledge ↑
