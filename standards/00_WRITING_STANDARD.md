
# Zanistarast Formal Writing Standard
Version 1.0

---

# Purpose

This document defines the official writing standard for all documents
inside the Zanistarast ecosystem.

Every repository shall follow these rules.

---

# Rule 1

Definitions always precede axioms.

---

# Rule 2

Axioms always precede lemmas.

---

# Rule 3

Lemmas always precede theorems.

---

# Rule 4

Every theorem must reference

• Definitions

• Axioms

• Previous Lemmas

---

# Rule 5

Every mathematical symbol must be declared inside

mathematics/00_NOTATION.md

before being used.

---

# Rule 6

Every concept must first appear inside

mathematics/01_DEFINITIONS.md

before becoming an axiom.

---

# Rule 7

No duplicate definitions.

Every concept has exactly one canonical definition.

---

# Rule 8

Every document begins with

Purpose

Notation (if required)

Dependencies

---

# Rule 9

Every document ends with

References

Dependencies

Future Work

---

# Rule 10

Every mathematical statement shall be classified as

Definition

Axiom

Lemma

Theorem

Corollary

Proof

Algorithm

Simulation

Remark

Conjecture

---

# Rule 11

Repository dependency shall be explicit.

No document may silently depend on another repository.

---

# Rule 12

Every major change increments the document version.

Example

v1.0

v1.1

v2.0
