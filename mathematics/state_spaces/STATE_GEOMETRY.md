# Purpose

This document defines the geometric structure of admissible state spaces
within the Zanistarast Formal Foundations.

---

# Geometric Interpretation

Every admissible state

Ψ

is represented as a point in the global state space.

---

# State Space

Ω

contains every admissible system configuration.

---

# Curves

A trajectory

γ

is a continuous or discrete sequence of admissible states.

γ : [0,T] → Ω

---

# Neighborhoods

Every admissible state possesses a neighborhood of nearby admissible
states.

---

# Distance

Distances are defined through the state metric.

---

# Reachability

A state is reachable if there exists an admissible trajectory connecting
the initial state to the target state.

---

# Geodesics

A geodesic is a trajectory minimizing the chosen state cost.

---

# Curvature

Curvature measures structural complexity of the admissible state space.
